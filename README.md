# Pigeon

Pigeon is a decentralized, offline-first mesh networking Android application. Built for situations where conventional communication infrastructure is unavailable or compromised, Pigeon enables users to maintain situational awareness, broadcast critical events, and communicate seamlessly using peer-to-peer Bluetooth and Wi-Fi mesh networking.

## Key Features
* **Offline Mesh Networking:** Utilizes robust peer-to-peer networking (Nearby Connections) to broadcast and sync data across nearby devices entirely without internet access.
* **Map Interface:** Features an interactive MapLibre-powered map with real-time GeoJSON rendering to visualize user proximity (500m radii) and track active events.
* **Event Wizard:** Rapidly create and broadcast mission-critical events to peers within your localized mesh network.
* **Identity & Security:** Includes a specialized onboarding flow with a 72-hour identity lock screen to ensure operational integrity.
* **Modern UI:** Built from the ground up with Jetpack Compose. The interface prioritizes high contrast, battery efficiency, and an "offline-ready" aesthetic using signature colors like Tactical Sand and Operational Gold.

## Applications
* **Disaster Relief & Emergency Response:** Coordinate team movements and share hazard locations when cellular towers are down.
* **Off-Grid Outdoor Excursions:** Keep hiking or exploration groups connected in remote areas with zero cell coverage.
* **Situational Awareness:** Provide secure, localized, and resilient situational awareness for teams operating in close proximity.

## Tech Stack
* **Language:** Kotlin 2.0
* **UI Framework:** Jetpack Compose & Jetpack Navigation
* **Local Storage:** Room Database
* **Networking:** Nearby Connections API (Bluetooth / Wi-Fi Direct)
* **Mapping:** MapLibre GL Android
